What Agent2WhatsApp does

Agent2WhatsApp is a self-hosted bridge between your AI agents and your personal WhatsApp. It runs as a small Express server that keeps one authenticated WhatsApp Web session open on your machine or VPS. Any agent — a Python script, a LangChain chain, a Flowise flow, a custom GPT tool call — sends a plain JSON payload to /send, and the service delivers it as a WhatsApp message. You scan a QR code once; after that, it is just HTTP.

Request lifecycle

How a message actually gets there

Four steps, in order, from agent output to notification on your phone.

01

Agent finishes a task

Your agent — in any language or framework — builds a short summary of what it did.

02

POST to /send

It sends { "phone", "text" } as JSON to your running microservice.

03

Local session forwards it

whatsapp-web.js relays the message through your already-authenticated WhatsApp session.

04

Message arrives

You get it on your phone like any other WhatsApp message — no app to install.

Why teams reach for it

Independent gateway

Runs a local, session-based WhatsApp Web client. No official Cloud API approval, no per-conversation pricing.

Works with any agent

Python, LangChain, Flowise, custom GPTs, or anything else that can make a standard HTTP POST request.

Token-optimized

Formatting and routing live in the middleware, so your LLM only ever needs to output a short summary string.

Scan once, stay connected

LocalAuth persists your WhatsApp session to disk, so the QR code only needs to be scanned the first time.

30-second integration

Notify yourself from Python

Once the microservice is running and authenticated, this is the entire client side.

Python 
import requests

def notify_whatsapp(summary):
    payload = {
        "phone": "968XXXXXXXX",
        "text": f"🤖 Agent Task Completed!\n\n{summary}"
    }
    requests.post("http://localhost:4000/send", json=payload)

Frequently asked questions

A free, open-source Node.js microservice that exposes one HTTP endpoint. Send it a phone number and a text message, and it forwards that message over a local WhatsApp Web session. It eliminates the need for Meta's official Cloud API, saving developers from per-conversation fees and template approval processes.

No. It uses whatsapp-web.js to drive a local, session-based WhatsApp Web client authenticated once by QR code. This approach completely avoids Meta's per-conversation fees, template approval requirements, and business verification processes that are mandatory for the official WhatsApp Business API.

Any framework or language capable of an HTTP POST with a JSON body can integrate with Agent2WhatsApp. This includes Python scripts, LangChain chains, Flowise flows, custom GPT tool calls, AutoGPT, CrewAI, and any other AI agent system capable of HTTP requests.

Yes. 100% free and open source under the MIT License. There are no per-message fees, no per-conversation charges, no subscription tiers, and no hidden costs. You can use it for personal projects, commercial applications, and everything in between.

Installation requires Node.js installed on your machine. Clone the GitHub repository, run npm install to install dependencies, then npm start to launch the microservice. On first run, scan the QR code with your WhatsApp mobile app to authenticate the session. The session persists locally, so you only need to scan once.

Agent2WhatsApp uses LocalAuth to persist your WhatsApp session securely to disk. For production deployments, run it behind a firewall or VPN, use authentication tokens for the /send endpoint, and ensure your server environment is secured. The tool itself does not store message content after delivery.
