What Agent2WhatsApp does

Agent2WhatsApp is a self-hosted bridge between your AI agents and your personal WhatsApp. It runs as a small Express server that keeps one authenticated WhatsApp Web session open on your machine or VPS. Any agent — a Python script, a LangChain chain, a Flowise flow, a custom GPT tool call — sends a plain JSON payload to /send, and the service delivers it as a WhatsApp message. You scan a QR code once; after that, it's just HTTP.

How a message actually gets there

Four steps, in order, from agent output to notification on your phone.

01

Agent finishes a task

Your agent — in any language or framework — builds a short summary of what it did.

02

POST to /send

It sends { "phone", "text" } as JSON to your running microservice.

03

Local session forwards it

whatsapp-web.js relays the message through your already-authenticated WhatsApp session.

04

Message arrives

You get it on your phone like any other WhatsApp message — no app to install.

30-second integration

Notify yourself from Python

Once the microservice is running and authenticated, this is the entire client side. 

import requests

def notify_whatsapp(summary):
    payload = {
        "phone": "968XXXXXXXX",
        "text": f"🤖 Agent Task Completed!\n\n{summary}"
    }
    requests.post("http://localhost:4000/send", json=payload)

Frequently asked questions

What is Agent2WhatsApp?

A free, open-source Node.js microservice that exposes one HTTP endpoint. Send it a phone number and a text message, and it forwards that message over a local WhatsApp Web session.

Does it use the official WhatsApp Business API?

No. It uses whatsapp-web.js to drive a session-based WhatsApp Web client authenticated once by QR code, avoiding Meta's per-conversation fees and template approval process.

Which AI agent frameworks can send messages through it?

Any framework or language capable of an HTTP POST with a JSON body — Python, LangChain, Flowise, and custom GPT tool calls all work out of the box.

Is it free?

Yes. 100% free and open source under the MIT License, with no per-message or per-conversation charges.
